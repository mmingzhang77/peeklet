# Security

If you find a security issue, please avoid posting exploit details, personal photos, private file paths, credentials, or other sensitive information in a public issue. You can open a brief issue asking the maintainers for a private way to discuss the report, without including the sensitive details.

Please include the Peeklet version, macOS version, and clear reproduction steps when you report a problem. Use synthetic test images and remove personal information from any logs or screenshots.

Peeklet's floating preview is a convenience feature, not an encryption system or a defense against screenshots and screen recording. Read [PRIVACY.md](PRIVACY.md) for its data handling and limitations.
